# Project Instructions

Follow the universal instructions in `C:\GitHub\AGENTS.md` when available. The portable workflow is summarized in `docs/Repository-Workflow.md`.

- This project is a fantasy, turn-based RPG video game.
- Keep confirmed design decisions distinct from proposals and open questions in `docs/Game-Design.md`.
- Plan the game collaboratively with the user. Do not treat suggested mechanics, engines, platforms, or story ideas as approved decisions.
- Commit and push tracked changes. Preserve unrelated local work.
- Application code requires a GitHub issue. Use `codex/<issue#>-<issuetitle>` feature branches based on `dev`, with `main` as fallback only when `dev` is unavailable.
- Follow the documented review and release workflow. Do not merge while blocking feedback or unresolved review comments remain.
- For PR completion, wait for the ChatGPT Codex Connector bot's thumbs-up or review comment. If it leaves review comments, ask the user how to proceed before merging.
- If Visual Studio is needed, use Visual Studio 2026 Insider Preview, not the default installation.
- Respond in English. Confirm the intended meaning of unexpected non-English user input before acting.

Engine-specific build, test, asset, and tooling instructions will be added after the technology choice is agreed.
